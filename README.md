# Customer Analytics: Segmentation, Churn & Lifetime Value

An end-to-end customer analytics project in three parts: who the customers are, who is likely to leave, and how much they are worth. Each part goes from raw data to concrete marketing recommendations.

Final project for the course AI for Communication & Marketing

## 🗂️ Project structure
| Part | Question | Methods |
|---|---|---|
| 1. Segmentation | Who are our customers? | RFM, K-Means |
| 2. Churn | Who is likely to leave? | Logistic Regression, Random Forest |
| 3. CLV | How much is each customer worth? | BG/NBD, Gamma-Gamma |


## 1️⃣ Segmentation

Cleaned customer data, explored what drives spending, and grouped customers with RFM scoring and K-Means clustering to tailor communication for each segment.

## 2️⃣ Churn Prediction

Predicted which e-commerce customers are likely to leave using Logistic Regression and Random Forest, handling class imbalance and identifying the main churn drivers.

## 3️⃣ Customer Lifetime Value

Forecast 90-day customer value with BG/NBD + Gamma-Gamma and Random Forest regression, and turned the results into a win-back campaign.

## 🛠️ Tools
Python · pandas · NumPy · scikit-learn · lifetimes · Matplotlib · Seaborn · Jupyter
